Хімічні та математичні формули

  1. H2O — формула води
  2. CO2 — вуглекислий газ
  3. H2SO4 — сульфатна кислота
  4. C6H12O6 — глюкоза
  5. CH4 + 2O2 → CO2 + 2H2O — реакція горіння метану
  6. a2 + b2 = c2 — теорема Піфагора
  7. (a + b)2 = a2 + 2ab + b2 — квадрат суми
  8. E = mc2 — формула еквівалентності маси та енергії
  9. x1,2 = (−b ± √(b2 − 4ac)) / 2a — корені квадратного рівняння
